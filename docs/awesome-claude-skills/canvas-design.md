# canvas-design

## 定位

通过「设计哲学 + 视觉表达」的两步法，创建原创的视觉艺术作品（PNG / PDF）。强调空间、形式、色彩、构图等视觉语言，将文本信息压缩到 10% 以内。

## 触发时机

- 需要生成海报、视觉设计、静态艺术品时
- 用户要求「有设计感」「像设计师做的」视觉输出时
- 需要为品牌或活动创建原创视觉素材时
- **不适用**：需要大量文字说明的信息图、纯数据图表

## 核心能力

1. **设计哲学生成**：为每次创作定义一个独特的「美学运动」（如 "Brutalist Joy"、"Chromatic Silence"），撰写 4-6 段视觉宣言
2. **视觉优先表达**：最终作品 90% 为视觉设计，10% 为必要文本，文字作为视觉元素而非说明段落
3. **多格式输出**：支持 `.png` 和 `.pdf` 格式
4. **原创性保障**：明确禁止复制现有艺术家作品，避免版权风险

## 指令流程概览

1. **创建设计哲学**（`.md` 文件）：
   - 命名运动（1-2 个词）
   - 撰写视觉宣言（空间与形式、色彩与材质、尺度与节奏、构图与平衡）
   - 反复强调「大师级工艺感」—— 作品应看起来像是经过无数小时精心打磨的
2. **视觉表达**（`.png` 或 `.pdf` 文件）：
   - 接收设计哲学
   - 通过画布将其实现为视觉作品
   - 信息通过空间、形式、色彩传递，而非段落

## 设计哲学示例

| 运动名称 | 核心理念 | 视觉表达 |
|---------|---------|---------|
| Concrete Poetry | 通过纪念碑式形式和粗体几何传递信息 | 巨大色块、雕塑感排版、粗野主义空间分割 |
| Chromatic Language | 色彩作为主要信息系统 | 几何精度、色彩区域创建意义、极简标签 |
| Analog Meditation | 通过纹理和呼吸空间进行安静的视觉沉思 | 纸张纹理、墨水晕染、大量负空间 |
| Organic Systems | 自然聚集和模块化生长模式 | 有机形态、自然色彩、空间关系图 |
| Geometric Silence | 纯粹的秩序与克制 | 网格精度、大胆摄影、瑞士形式主义 |

## 与 ys-powers 的关联

- **与 canvas-design 的差异化**：ys-powers 的 `html-anything` 也生成视觉输出，但 `canvas-design` 更专注于「纯视觉艺术」而非「信息呈现」，其「设计哲学先行」的方法论值得借鉴
- **借鉴价值**：「设计哲学 → 视觉表达」的两步法可纳入任何需要高质量视觉输出的 skill 中；反 AI slop 的理念与 `artifacts-builder` 一脉相承
- **搬运建议**：若 ys-powers 有品牌设计、海报生成等场景，值得搬运或改编
