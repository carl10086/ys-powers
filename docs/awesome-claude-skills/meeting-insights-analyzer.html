定位

Meeting Insights Analyzer 是一个专注于会议沟通效能提升的分析工具。它通过系统性地解析会议转录文本，提取可量化的沟通行为指标，并提供基于证据的改进建议。

🏆核心价值主张

将非结构化的会议对话转化为结构化的沟通洞察，帮助用户：

  • 识别自身沟通模式中的盲点和惯性
  • 获取具体、可操作的改进建议（附带时间戳证据）
  • 追踪沟通能力随时间的成长轨迹
  • 在绩效评审和团队辅导中提供数据支撑
⚠

前提条件：此 skill 需要高质量的会议转录文件（含说话人标签和时间戳）才能发挥最佳效果。无转录文件时无法使用。

触发时机

明确何时应该激活此 skill，以及何时应该寻找替代方案。

✅适用场景

  • 需要回顾自己的会议表现并获取具体反馈时
  • 准备绩效评审，需要沟通能力的具体例证时
  • 辅导团队成员改进沟通风格时
  • 追踪一段时间内的沟通能力成长趋势时
  • 识别自己在会议中是否回避冲突、主导对话或忽略倾听时

❌不适用场景

无会议转录文件可用时。此 skill 完全依赖文本数据，没有转录就无法进行分析。

核心能力

Meeting Insights Analyzer 提供四个相互关联的分析能力，从模式识别到趋势追踪形成完整闭环。

🔍1. 模式识别

跨多场会议识别重复行为模式，包括：

  • 冲突回避或间接沟通 — 检测模糊语言、委婉表达和回避策略
  • 发言比例和轮流发言模式 — 量化个人在会议中的话语占比
  • 提问 vs 陈述的比例 — 区分探究性沟通与宣告性沟通
  • 积极倾听指标 — 识别复述、确认和跟进问题
  • 决策方式 — 分析共识构建 vs 独断决策的倾向

📈2. 沟通效果分析

评估沟通的多维效果：

  • 清晰度和直接性 — 信息传达的明确程度
  • 填充词和模糊语言 — "um"、"like"、"kind of"、"maybe" 等使用频率
  • 语调和情绪模式 — 情绪表达的一致性和适应性
  • 会议控制和引导能力 — 话题管理和时间把控

💡3. 可操作建议

提供带时间戳的具体示例，每个建议包含三个要素：

  • 发生了什么 — 具体的对话片段和行为描述
  • 为什么重要 — 该行为对沟通效果的影响分析
  • 如何改进 — 可执行的具体替代方案

🚀4. 趋势追踪

对比多场会议的数据，展示成长轨迹。通过纵向对比，用户可以看到自己在特定维度上的进步或退步。

指令流程概览

四步标准化分析流程，确保每次分析都系统、全面、有针对性。

步骤 动作 输出
1. 发现可用数据 扫描文件夹中的转录文件（.txt、.md、.vtt、.srt、.docx） 可用文件清单及格式确认
2. 明确分析目标 确认用户关注的行为类型（冲突回避、打断、填充词等） 聚焦的分析维度列表
3. 分析模式 针对每个关注点提取具体证据和时间戳 带证据的行为模式报告
4. 生成报告 输出结构化洞察，包含正面案例和改进建议 完整分析报告

常用分析维度

四个关键维度的识别信号和解读方式。

维度 识别信号
冲突回避 模糊语言（"maybe"、"I think"）、间接请求代替直接表达
发言比例 计算用户发言时长占总时长的百分比
积极倾听 复述对方观点、提出跟进问题、适时确认
会议控制 引导话题转移、总结决议、分配行动项
分析提示

高质量的分析需要转录文件包含说话人标签和时间戳。纯文本转录仍可分析，但无法提供精确的时间定位和行为上下文。

使用前的关键问题

数据准备

你是否拥有带说话人标签和时间戳的会议转录文件？

分析聚焦

你最关注哪个沟通维度：冲突处理、发言习惯、倾听质量还是会议引导？

时间跨度

你希望分析单次会议还是追踪一段时间内的成长趋势？

应用场景

分析结果将用于个人改进、绩效评审还是团队辅导？
