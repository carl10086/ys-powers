Skill Documentation

Changelog Generator

将技术性的 Git 提交历史自动转换为用户友好的发布日志（changelog），把开发语言翻译成客户语言，减少手动整理发布说明的时间。

来源：refer/awesome-claude-skills/changelog-generator/SKILL.md
维护者：Composio / 社区 | 许可证：Apache 2.0

定位

Changelog Generator 是一个专注于发布内容生产的自动化工具。它填补了从代码变更到用户沟通之间的空白，将开发者视角的技术提交转换为终端用户能够理解和欣赏的产品更新说明。

"把开发语言翻译成客户语言，减少手动整理发布说明的时间。"

触发时机

在以下场景中，Changelog Generator 能够发挥最大价值：

  • 准备新版本发布说明时
  • 需要写周报、月报形式的产品更新摘要时
  • 向客户或用户文档化变更时
  • 为应用商店提交或更新通知撰写 changelog 时
  • 维护公开的 changelog 或产品更新页面时

不适用场景

内部纯技术重构、无用户可见变更的提交 —— 这类提交会被自动过滤，不进入最终输出。

核心能力

Capability 01
扫描 Git 历史

分析特定时间段或版本之间的提交记录

Capability 02
智能分类

自动归入 Features、Improvements、Bug Fixes、Breaking Changes、Security 等类别

Capability 03
语言翻译

将开发者提交信息转换为面向客户的清晰描述

Capability 04
噪声过滤

自动排除内部提交（重构、测试、CI 等无用户价值的内容）

Capability 05
品牌语调适配

可结合品牌风格指南统一输出语气

指令流程概览

  1. 确定范围 — 时间范围或版本区间（如 "自上次发布以来"、"过去一周"、"v2.4.0 到 v2.5.0"）
  2. 扫描历史 — 提取对应区间的 Git 提交记录
  3. 分类过滤 — 按类别分组并过滤内部提交
  4. 语言转换 — 将技术描述翻译为客户语言
  5. 格式化输出 — 生成结构化 changelog（Markdown 格式）

使用方式

通过自然语言指令触发，支持以下典型用法：

Create a changelog from commits since last release
Generate changelog for all commits from the past week
Create release notes for version 2.5.0
Create a changelog for commits since v2.4.0, using my changelog guidelines from CHANGELOG_STYLE.md

输出示例

Markdown Output
# Updates - Week of March 10, 2024

## ✨ New Features

- **Team Workspaces**: Create separate workspaces for different projects.
- **Keyboard Shortcuts**: Press ? to see all available shortcuts.

## 🔧 Improvements

- **Faster Sync**: Files now sync 2x faster across devices
- **Better Search**: Search now includes file contents
