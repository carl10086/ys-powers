为什么重要

Real-graph 是 Twitter 推荐系统的核心组件，它直接决定了你的推文能否获得初始曝光。高 Real-graph 得分意味着你的内容更有可能被推送给粉丝。

三个实用技巧

  • 在推文开头提出问题，激发用户回复欲望
  • 使用投票功能增加互动率
  • 回复评论延长对话链条
