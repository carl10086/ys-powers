定位

connect-apps 的物理插件载体，通过 claude --plugin-dir 安装到 Claude Code 中，为 Claude 提供 500+ 应用的自动化执行能力。

插件化部署：将 Composio 能力打包为 Claude Code 可识别的插件格式，安装后 Claude 可发送邮件、创建 Issue、发布消息、更新文档等。

触发时机

安装阶段
需要通过 claude --plugin-dir 方式安装 Composio 插件时
配置阶段
已安装并运行 /connect-apps:setup 进行初始化配置时
不适用场景
使用 Python/TypeScript SDK 直接集成的场景（此时用 connect）

核心能力

能力说明
插件化部署将 Composio 能力打包为 Claude Code 可识别的插件格式
自动认证管理内置 OAuth 流程处理，用户只需粘贴 API Key
500+ 应用覆盖安装后 Claude 可发送邮件、创建 Issue、发布消息、更新文档等

安装流程

  1. 安装插件 
    claude --plugin-dir ./connect-apps-plugin
  2. 在 Claude Code 中运行配置 
    /connect-apps:setup
  3. 粘贴 API Key
    从 platform.composio.dev 获取的免费 API Key
  4. 重启 Claude Code
    完成安装后重启以加载插件能力
