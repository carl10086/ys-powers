01

定位

skill-share 是一个 Claude Skill 分发工具，它将 Skill 创建、结构验证、自动打包和团队通知整合为一条完整的流水线。它的核心目标是消除 Skill 开发完成后分发到团队的 friction，让 Skill 从"本地可用"变为"团队共享"的过程完全自动化。

核心承诺
"创建 Skill 后，一条命令完成验证、打包、通知 —— 团队成员即刻可用。"

与仅用于本地个人使用的 Skill 不同，skill-share 假设 Skill 是需要团队协作维护的资产。它通过标准化的目录结构、自动化的质量检查和即时通讯集成，确保分发的 Skill 符合团队规范且触达率最大化。

02

触发时机

以下场景适合使用 skill-share：

✓ 适用场景
  • 创建新 Skill 后需要分发给团队成员时
  • 需要验证 Skill 结构是否符合规范时
  • 希望将 Skill 打包为可分发格式（zip）时
  • 需要自动化 Skill 开发和团队通知流程时
✗ 不适用场景

Skill 仅个人使用、无需团队协作时 —— 此时额外的验证和通知步骤是不必要的 overhead。

03

核心能力

skill-share 提供四项核心能力，覆盖 Skill 从创建到分发的全生命周期：

📄
Skill 创建
自动生成标准目录结构（SKILL.md、scripts/、references/、assets/）和 YAML frontmatter
✅
结构验证
检查 SKILL.md 格式、必填字段和命名规范（hyphen-case）
📦
自动打包
生成包含所有资源和文档的可分发 zip 文件
💬
Slack 集成
通过 Rube 自动将 Skill 信息发送到指定 Slack 频道
04

指令流程概览

skill-share 的执行流程分为五个阶段，形成完整的 Skill 分发流水线：

1
初始化
提供 Skill 名称和描述，触发创建流程
↓
2
创建
生成标准 Skill 目录结构，包括 SKILL.md 模板和必要的子目录
↓
3
验证
检查元数据完整性和命名规范，确保符合团队标准
↓
4
打包
创建 zip 分发包，包含所有相关资源和文档
↓
5
通知
通过 Slack 向团队发送 Skill 创建通知，附带元数据和下载链接
05

Slack 集成能力

skill-share 通过 Rube 平台调用 Slack API 实现团队通知，支持三种核心操作：

💬 Slack 工具集
通过 Rube 调用以下工具实现自动化通知：
SLACK_SEND_MESSAGE SLACK_POST_MESSAGE_WITH_BLOCKS SLACK_FIND_CHANNELS
工具 用途 触发时机
SLACK_SEND_MESSAGE 发送 Skill 基本信息 Skill 创建完成后
SLACK_POST_MESSAGE_WITH_BLOCKS 分享格式化的 Skill 元数据 需要富文本展示时
SLACK_FIND_CHANNELS 发现目标频道 首次配置或频道变更时
06

使用示例

以下示例展示创建名为 "pdf-analyzer" 的 Skill 的完整流程：

user: Create a skill called "pdf-analyzer"

执行流程：

  1. 创建 /skill-pdf-analyzer/ 目录
  2. 生成 SKILL.md 模板，包含标准 YAML frontmatter
  3. 创建 scripts/、references/、assets/ 子目录
  4. 验证结构：检查必填字段、命名规范（hyphen-case）
  5. 打包为 zip：包含所有资源和文档
  6. Slack 通知："New Skill Created: pdf-analyzer — Advanced PDF analysis capabilities"
输出示例
Slack 通知将包含 Skill 名称、描述、创建者、打包文件链接和快速安装指令。
