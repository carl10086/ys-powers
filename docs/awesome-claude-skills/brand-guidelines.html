Brand Guidelines

Anthropic Brand Styling

将 Anthropic 官方品牌色与字体应用到任意需要统一视觉风格的 Artifact 中， 确保输出符合 Anthropic 的品牌识别标准。主色、强调色与字体系统智能适配， 保持品牌一致性的同时保留原有内容结构。

定位与触发时机

本规范用于将 Anthropic 官方品牌色与字体应用到任意需要统一视觉风格的 Artifact 中。 确保输出符合 Anthropic 的品牌识别标准，在保持品牌一致性的同时保留原有内容结构。

适用场景

需要保持与 Anthropic 品牌一致的视觉风格时；创建对外展示的公司级文档、幻灯片或报告时；用户明确要求使用 Anthropic 品牌色或字体时。

不适用场景：纯内部草稿、无品牌要求的个人项目。请勿在无需品牌一致性的场景下强制应用本规范，避免过度设计。

品牌色彩系统

Anthropic 品牌色分为主色与强调色两组。 主色用于文本与背景，强调色用于图形点缀与视觉层次。

主色

Dark #141413
Light #faf9f5
Mid Gray #b0aea5
Light Gray #e8e6dc

强调色

Orange #d97757
Blue #6a9bcc
Green #788c5d
配色模式 主色 + 强调色循环的配色模式可借鉴到 html-anything 等生成 HTML 的 skill 中，作为品牌一致性的样式基准。

字体系统

Anthropic 品牌字体采用双字体策略：标题使用无衬线字体建立现代感， 正文使用衬线字体提升阅读体验。系统无字体时自动回退到 Arial / Georgia。

Poppins — 标题字体
Lora — 正文字体。专为屏幕阅读优化，具有温和的衬线与舒适的字间距， 适合长文阅读与文档展示。
标题: Poppins (24pt+) / 回退: Arial
正文: Lora / 回退: Georgia
  • 标题（24pt+）：Poppins，字重 600-700，字间距略微收紧
  • 正文：Lora，字重 400，行高 1.5-1.6，最佳阅读尺寸 14-16px
  • 等宽文本：SF Mono / Menlo，用于代码、数值、标识符

核心能力

  • 品牌色自动应用
    主色（Dark #141413、Light #faf9f5）与强调色（Orange #d97757、Blue #6a9bcc、Green #788c5d） 根据背景明暗自动适配，确保对比度与可读性。
  • 字体智能切换
    标题自动应用 Poppins（回退 Arial），正文自动应用 Lora（回退 Georgia）， 自动处理字体缺失情况，无需手动干预。
  • 图形着色
    非文本形状循环使用橙、蓝、绿三色作为点缀，保持视觉节奏与品牌一致性。
  • 文本层级保持
    在应用品牌样式的同时完整保留原有文本结构、格式与语义层级。

应用流程

  1. 识别 artifact 中需要应用品牌的元素（文本、形状、背景）
  2. 根据背景明暗自动选择主色或反色
  3. 标题（24pt+）应用 Poppins 字体，正文应用 Lora 字体
  4. 非文本图形元素依次分配橙、蓝、绿强调色
  5. 输出符合 Anthropic 品牌规范的格式化结果

技术细节

颜色实现

颜色通过 RGB 值精确匹配，使用 python-pptx 的 RGBColor 类实现。在 Web 环境中直接使用 HEX 值或 RGB 等效值。

字体管理

字体依赖系统预装，无字体时自动回退到 Arial / Georgia。无需额外安装字体即可工作，但预装 Poppins 和 Lora 可获得最佳效果。

兼容性

支持 PPTX、HTML、PDF 等多种输出格式。在 Web 环境中通过 Google Fonts 或本地字体加载实现。

与 ys-powers 的关联

  • 现有能力关系：ys-powers 中暂无专门的品牌/视觉规范 skill， brand-guidelines 可作为前端/UI 相关输出的样式基准。
  • 借鉴价值：其「主色 + 强调色循环」的配色模式可借鉴到 html-anything 等生成 HTML 的 skill 中。
  • 搬运建议：价值中等。若 ys-powers 经常需要输出带品牌一致性要求的文档，可考虑搬运。

集成考量

  • 是否应提供品牌色开关，允许用户选择「品牌模式」或「中性模式」？
