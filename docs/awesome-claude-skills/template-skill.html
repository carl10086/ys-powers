Claude Skill / 标准模板

template-skill — Claude Skill 的标准模板

提供最小可运行的目录结构和文件骨架，作为创建新 Skill 的起点。包含标准 YAML frontmatter、Markdown 指令格式，以及与 ys-powers 生态的关联说明。

01

定位

Claude Skill 的标准模板，提供最小可运行的目录结构和文件骨架，作为创建新 Skill 的起点。

02

触发时机

适用场景
  • 从零开始创建新 Claude Skill 需要参考标准结构时
  • 快速搭建 Skill 原型验证想法时
  • 教学演示 Skill 的基本组成部分时
不适用场景
  • 已有成熟 Skill 需要修改
  • 使用 skill-creator / skill-share 自动生成时
03

核心能力

1. 最小结构
提供标准目录布局和必需的 YAML frontmatter
2. 快速启动
复制模板后即可开始编写 Skill 逻辑
3. 规范示例
展示正确的 name 和 description 格式
04

目录结构

template-skill/
└── SKILL.md          # 必需：包含 YAML frontmatter + Markdown 指令
设计要点
极简的单文件结构 —— 整个 Skill 仅需一个 SKILL.md 文件即可运行，体现了 Claude Skills "最小可运行" 的设计理念。
05

模板内容

---
name: template-skill
description: Replace with description of the skill and when Claude should use it.
---

# Insert instructions below
关键约束
description 字段至关重要 —— 它直接决定 Claude 何时触发该 Skill。描述应当清晰说明 Skill 的功能和适用场景，避免过于笼统导致误触发或遗漏触发。
06

与 ys-powers 的关联

与 skill-creator 的关系

template-skill 是「最小模板」，skill-creator 是「完整开发指南」。前者适合快速启动，后者适合深度设计。

借鉴价值

无特别独特的设计，但其极简结构可作为 ys-powers 内部快速创建 Skill 的脚手架。

搬运建议

低价值。模板本身过于简单，建议直接使用 skill-creator 的能力。

  • 是否需要从零创建新 Skill，而非修改现有 Skill？
  • 是否需要快速验证一个 Skill 想法，而非完整设计？
  • 是否已了解 skill-creator 的能力，确认不需要更完整的开发指南？
  • 是否正确填写了 name 和 description 字段？
