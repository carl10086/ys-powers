slack-gif-creator

创建针对 Slack 优化的动画 GIF，提供符合 Slack 尺寸约束的验证器和可组合的动画原语（shake、bounce、move 等）。覆盖「静→动→优化」视觉生产链路的动画环节。

定位与触发时机

slack-gif-creator 是一个面向 Slack 生态的专用动画 GIF 创作技能。它在以下场景触发：

  • 需要为 Slack 制作表情包（emoji）或消息动图时
  • 用户描述类似 "make me a GIF for Slack of X doing Y" 的需求时
  • 需要确保 GIF 符合 Slack 的严格大小限制时
不适用场景

非 Slack 场景的通用 GIF 制作。虽然工具可用，但优化方向不同，可能无法达到最佳文件大小与画质平衡。

核心能力

1. Slack 约束验证

自动检查 GIF 是否符合 Slack 的消息或 emoji 尺寸限制，避免上传失败。

2. 动画原语

提供可组合的动画基础模块：Shake（抖动）、Bounce（弹跳）、Move（移动）、Kaleidoscope（万花筒）。

3. 尺寸优化策略

针对 Slack 的严格限制提供自动优化建议，包括帧率、颜色数、分辨率调整。

4. 辅助工具

文本渲染、颜色处理、特效叠加等可选工具，支持更丰富的视觉表达。

Slack GIF 规格

类型 最大尺寸 推荐尺寸 FPS 颜色 时长
消息 GIF ~2 MB 480×480 15-20 128-256 2-5s
Emoji GIF 64 KB 128×128 10-12 32-48 1-2s

Emoji GIF 优化策略

Emoji GIF 面临最严苛的 64 KB 限制，需要采用激进的优化策略：

  • 限制总帧数 10-15 帧，减少冗余画面
  • 使用 32-48 色，降低调色板大小
  • 设计简洁，避免渐变和复杂纹理
  • 频繁验证文件大小，迭代调整
关键洞察：Emoji GIF 的优化核心在于「减少信息熵」—— 通过简化视觉元素和缩短时长，在极小的体积内保留动画的辨识度。

验证器使用

技能内置 Python 验证器，支持完整验证和快速检查两种模式：

# 完整验证
from core.validators import validate_gif, is_slack_ready

all_pass, results = validate_gif('emoji.gif', is_emoji=True)

# 快速检查
if is_slack_ready('emoji.gif', is_emoji=True):
    print("Ready to upload!")

validate_gif 返回详细的检查结果列表，is_slack_ready 返回布尔值，适合在流水线中做快速门控。

与 ys-powers 的关联

技能链路关系

slack-gif-creator 与 ys-powers 中其他视觉技能形成完整生产链路：

  • canvas-design：创作静态视觉艺术
  • image-enhancer：优化现有图片
  • slack-gif-creator：创作 Slack 专用动画

三者覆盖「静→动→优化」的完整视觉生产链路。

设计模式借鉴

其「约束验证器 + 可组合原语」的设计模式可复用到任何需要「在严格约束下创作」的场景，例如：

  • 社交媒体内容（Twitter/X 图片尺寸限制）
  • 邮件签名（HTML 邮件客户端兼容性）
  • 小程序素材（微信小程序包大小限制）

搬运建议

低价值

功能高度聚焦 Slack 生态，适用面较窄。除非项目明确需要 Slack 表情包/动图制作能力，否则不建议搬运。
