Claude Skill Documentation

Lead Research Assistant

通过分析产品定位和理想客户画像（ICP），识别高质量潜在客户，提供按匹配度排序的线索列表和个性化的接触策略。

定位与触发时机

Lead Research Assistant 是一个专注于 B2B 销售研究场景的 Claude Skill，旨在帮助团队系统性地识别、评估和优先处理潜在客户线索。

适用场景

为产品或服务寻找潜在客户、准备合作伙伴或目标公司的 outreach 名单、进行销售拓展前调研目标账户、验证市场领域是否存在足够多的匹配客户。

不适用场景

B2C 场景、或产品定位尚不明确的早期探索阶段。该 Skill 假设已有清晰的产品定义和目标市场认知。

核心能力

1. 业务理解

分析产品价值主张、核心功能和解决的问题

2. ICP 定义

基于行业、公司规模、地理位置、技术栈、痛点等维度定义理想客户

3. 线索搜索

根据 ICP 搜索匹配的公司，利用招聘动态、技术栈、融资新闻等信号判断需求

4. 优先级排序

按匹配度（1-10 分）排序，考虑需求紧迫性、预算、竞争格局等

5. 接触策略

为每个线索提供个性化的 outreach 建议、决策人角色和 conversation starters

6. 数据丰富

收集决策人信息和公司上下文

指令流程概览

该 Skill 遵循一个结构化的五步流程，确保从理解产品到生成可执行线索的完整闭环：

步骤 动作 输出
1. 理解产品 分析代码库或产品描述，提取价值主张和核心功能 产品定位摘要
2. 定义 ICP 确定目标行业、公司规模、地理位置、痛点和技术要求 理想客户画像
3. 搜索线索 基于 ICP 搜索匹配公司，利用公开信号验证需求 候选线索清单
4. 评分排序 为每个线索计算匹配度分数并排序 优先级排序列表
5. 生成输出 提供公司名称、匹配理由、优先级、决策人、接触策略和价值主张 完整线索报告

输出格式

Skill 生成标准化的 Markdown 格式报告，包含以下结构：

报告结构：Summary（线索统计）→ Top Leads（按优先级排序的详细线索卡片）→ 每个线索包含：公司名称、网站、匹配理由、优先级评分（1-10）、决策人角色、接触策略、针对该公司的产品价值主张

与 ys-powers 的关联

与 competitive-ads-extractor 的关系

competitive-ads-extractor 分析竞品广告策略，lead-research-assistant 分析潜在客户。两者都属于市场情报范畴，方向互补。

借鉴价值

其「产品分析 → ICP 定义 → 信号搜索 → 评分排序 → 策略输出」的五步流程是通用的 B2B 销售研究方法论。

搬运建议

中等价值。适合有销售或 BD 需求的团队。注意线索数据的准确性依赖公开信息源。

使用建议

  • 确保产品定位清晰后再使用该 Skill，模糊的输入会导致模糊的输出
  • 结合 competitive-ads-extractor 使用，形成完整的市场情报工作流
  • 对生成的线索进行人工验证，公开信息可能存在滞后或不准确
  • 优先跟进 High priority（8-10 分）线索，它们通常具有最高的转化潜力
  • 定期更新 ICP 定义，随着产品演进，理想客户画像也会变化
