01

定位与触发时机

Skill 定位

作为个人文件整理助手，通过分析文件类型、日期和内容上下文，自动建议并执行文件重组、去重和清理，保持数字工作空间整洁。

适用场景

  • Downloads 文件夹混乱、找不到文件时
  • 怀疑有大量重复文件占用空间时
  • 项目目录结构不合理、需要重新规划时
  • 准备归档旧项目或清理过期文件时
  • 启动新项目需要建立规范的目录结构时
  • 当前正在频繁修改的活跃项目目录 不适用
02

核心能力

📊

结构分析

扫描目标目录，统计文件类型、大小分布、日期范围和现有组织问题

🔍

重复检测

跨系统识别重复文件，辅助用户决定保留哪个版本

💡

智能建议

基于文件类型（文档、图片、视频、代码等）或用途（工作、个人、归档）提出逻辑分组方案

⚡

自动整理

在用户确认后执行移动、重命名和分类操作

🧠

上下文保持

根据文件内容、修改时间和项目关联性做出智能决策

🧹

Clutter 清理

识别长期未访问的旧文件，建议归档或删除

03

指令流程概览

1

明确范围

确认目标目录、主要问题、需避开的敏感区域、整理激进程度

2

现状分析

使用 ls、find、du、file 等命令收集文件统计信息

3

模式识别

按类型、用途、时间等维度确定逻辑分组

4

方案呈现

向用户展示建议的目录结构和文件迁移计划

5

执行整理

在用户批准后执行移动/重命名，保留原始备份

04

常用分析命令

目录概览
ls -la <target_directory>
文件类型统计
find <target_directory> -type f | sed 's/.*\.//' | sort | uniq -c | sort -rn
最大文件
find <target_directory> -type f -exec du -h {} + | sort -rh | head -20
