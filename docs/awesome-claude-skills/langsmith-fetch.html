Claude Skill

langsmith-fetch

通过从 LangSmith Studio 获取 LangChain / LangGraph Agent 的执行轨迹（trace），帮助开发者调试 Agent 行为、分析工具调用、检查记忆操作和审查性能指标。

1

定位

langsmith-fetch 是一个面向 LangChain / LangGraph Agent 开发者的可观测性调试技能。它通过调用 LangSmith Studio API，获取 Agent 的执行轨迹数据，将原本分散在云端监控平台的 trace 信息拉取到本地开发环境，使开发者能够在调试会话中直接分析 Agent 的行为模式。

核心价值主张

将「云端 trace 数据」转化为「可操作的调试情报」，缩短从发现问题到定位根因的时间路径。

2

触发时机

适用场景

Agent 行为异常，需要查看最近执行记录时；调查工具调用失败或返回错误时；分析 Agent 的记忆（LTM）操作是否正常时；检查 Token 使用情况和执行性能时；需要向 LangSmith 获取特定 Trace ID 的详细信息时。

不适用场景

未使用 LangChain / LangGraph 构建 Agent，或未配置 LangSmith 监控时。此技能依赖于 LangSmith 平台的 trace 数据，如果项目未接入 LangSmith，则无法使用。

3

核心能力

1

快速调试

获取最近 N 分钟内的 traces，快速定位失败点和异常模式

2

深度分析

针对特定 trace ID 获取完整执行流程和 JSON 详情

3

错误定位

识别工具调用失败、连接超时、节点执行异常等问题

4

性能监控

查看执行时长、Token 消耗等关键指标

5

工具调用审计

追踪 Agent 调用了哪些工具、调用顺序和返回结果

4

指令流程概览

A

快速调试（最近活动）

扫描最近时间窗口内的 trace 活动，获取高频概览信息。

langsmith-fetch traces --last-n-minutes 5 --limit 5 --format pretty
  • 发现 traces 数量
  • 错误/失败项
  • 调用的工具列表
  • 执行时长
  • Token 使用量
B

深度调查（特定 Trace）

基于快速扫描中发现的异常 trace ID，进行单点深度钻取。

langsmith-fetch trace <trace-id> --format json
  • Agent 目标
  • 工具调用顺序和结果
  • 失败点和错误信息
  • 根因分析
  • 修复建议

两级调试模式

「最近活动快速扫描 → 特定 Trace 深度钻取」的两级调试模式是可观测性（observability）最佳实践，可复用到任何需要排查复杂执行流程的场景。

5

安装要求

# 安装 CLI 工具 pip install langsmith-fetch # 配置环境变量 export LANGSMITH_API_KEY="your_key" export LANGSMITH_PROJECT="your_project"

前置条件

需要有效的 LangSmith API Key 和已配置的项目名称。确保目标 Agent 已接入 LangSmith 监控，否则无法获取 trace 数据。
