定位

Connect 是 Claude 与外部世界之间的通用连接层。它通过 Composio 平台提供对 1000 多个主流 SaaS 应用的统一访问能力，使 Claude 能够从纯粹的文字生成助手转变为能够实际执行操作的智能代理。

无论是发送邮件、创建 GitHub Issue、更新 Notion 文档，还是跨多个应用串联复杂工作流，Connect 都能通过自然语言指令自动完成工具路由、授权管理和操作执行。

触发时机

在以下场景中，Connect 是首选能力：

  • 实际执行操作 — 需要 Claude 发送邮件、创建 Issue、发布 Slack 消息时
  • 数据操作 — 需要更新数据库、添加日历事件、管理 CRM 记录时
  • 跨应用工作流 — 需要串联多个应用的操作（如「从 GitHub 提取 bug 列表，总结后发 Slack」）时
不适用场景

仅需文字建议、无需实际执行的场景不需要启用 Connect。对于纯咨询、分析、总结类任务，Claude 的原生能力已足够。

核心能力

1000+ 应用集成

覆盖邮件（Gmail、Outlook）、聊天（Slack、Discord、Teams）、开发（GitHub、GitLab、Jira）、文档（Notion、Google Docs）、数据（Sheets、Airtable、PostgreSQL）、CRM（HubSpot、Salesforce）等全品类 SaaS 应用。

自然语言驱动

用日常语言描述需求，Claude 自动路由到正确工具。无需记忆特定命令或 API 名称。

自动 OAuth 处理

首次使用某应用时自动引导授权流程，无需手动配置密钥或令牌。

链式操作

支持跨应用工作流，一步完成多系统协作。例如：从 GitHub 提取数据 → 分析总结 → 发送 Slack 通知 → 更新 Notion 文档。

指令流程概览

Connect 的处理流程分为四个阶段，用户只需用自然语言描述需求，后续步骤自动完成：

1
自然语言描述
用户描述要执行的操作，如 "Send email to sarah@acme.com about the launch"
2
工具路由
Composio Tool Router 从 1000+ 工具中匹配最合适的工具
3
自动授权
如首次使用，自动触发 OAuth 授权流程
4
执行与反馈
执行操作并返回结果给用户

安装配置

Connect 需要 Composio API Key 和对应语言的 SDK。配置过程分为两步：

# 获取免费 API Key: platform.composio.dev
export COMPOSIO_API_KEY="your-key"

# Python
pip install composio

# TypeScript
npm install @composio/core
配置提示

首次使用某个应用时，系统会自动引导 OAuth 授权流程。用户只需在弹出的授权页面中确认权限即可，无需手动创建应用或配置回调地址。

与 ys-powers 的关联

与 composio-skills 的关系

connect 是 Composio 的「通用连接层」，提供「一句话执行任意操作」的通用能力；composio-skills 是「按应用细分的自动化 skill」，提供「按应用最佳实践编排」的结构化能力。两者互补：connect 负责快速执行，composio-skills 负责深度编排。

借鉴价值

其「自然语言 → 工具路由 → 自动执行」的交互模式是 Agent 与外部系统集成的标杆设计。该模式的核心洞察是：用户不应需要了解底层工具的细节，只需表达意图，系统负责翻译和执行。

搬运建议

高价值。若 ys-powers 的使用者需要频繁与外部 SaaS 交互，可搬运或参考实现类似的「通用连接层」skill，使本地 Claude 工作流也能享受到「一句话操作千款应用」的能力。
