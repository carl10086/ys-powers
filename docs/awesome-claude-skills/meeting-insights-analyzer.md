# meeting-insights-analyzer

## 定位

通过分析会议转录文本，识别沟通模式、行为倾向和可改进点，帮助用户成为更高效沟通者和领导者。

## 触发时机

- 需要回顾自己的会议表现并获取具体反馈时
- 准备绩效评审，需要沟通能力的具体例证时
- 辅导团队成员改进沟通风格时
- 追踪一段时间内的沟通能力成长趋势时
- 识别自己在会议中是否回避冲突、主导对话或忽略倾听时
- **不适用**：无会议转录文件可用时

## 核心能力

1. **模式识别**：跨多场会议识别重复行为：
   - 冲突回避或间接沟通
   - 发言比例和轮流发言模式
   - 提问 vs 陈述的比例
   - 积极倾听指标
   - 决策方式

2. **沟通效果分析**：评估：
   - 清晰度和直接性
   - 填充词（"um"、"like"）和模糊语言（"kind of"、"maybe"）的使用
   - 语调和情绪模式
   - 会议控制和引导能力

3. **可操作建议**：提供带时间戳的具体示例：
   - 发生了什么
   - 为什么重要
   - 如何改进

4. **趋势追踪**：对比多场会议的数据，展示成长轨迹

## 指令流程概览

1. **发现可用数据**：扫描文件夹中的转录文件（`.txt`、`.md`、`.vtt`、`.srt`、`.docx`）
2. **明确分析目标**：确认用户关注的行为类型（冲突回避、打断、填充词等）
3. **分析模式**：针对每个关注点提取具体证据和时间戳
4. **生成报告**：输出结构化洞察，包含正面案例和改进建议

## 常用分析维度

| 维度 | 识别信号 |
|------|---------|
| 冲突回避 | 模糊语言（"maybe"、"I think"）、间接请求代替直接表达 |
| 发言比例 | 计算用户发言时长占总时长的百分比 |
| 积极倾听 | 复述对方观点、提出跟进问题、适时确认 |
| 会议控制 | 引导话题转移、总结决议、分配行动项 |

## 与 ys-powers 的关联

- **与 internal-comms 的关系**：`internal-comms` 帮助「撰写」沟通内容，`meeting-insights-analyzer` 帮助「评估」沟通效果。两者互补
- **借鉴价值**：其「转录 → 模式识别 → 时间戳证据 → 改进建议」的分析框架可复用到任何需要「基于文本数据提取行为洞察」的场景
- **搬运建议**：中等价值。适合需要提升沟通效率的团队或个人。注意需要高质量的会议转录（含说话人标签和时间戳）
