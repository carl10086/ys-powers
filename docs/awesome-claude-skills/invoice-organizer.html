Claude Skill

invoice-organizer

自动读取发票和收据文件，提取关键信息（日期、金额、供应商等），按统一规则重命名并分类归档，将数小时的手动记账压缩为几分钟。

适用范围：适合自由职业者、小企业和需要自行管理财务的开发者。注意 OCR 准确性受图片质量影响。不适用：无发票文件、或仅需处理少量（< 5 张）且已有明确分类时。

01

定位与触发时机

核心定位

SCOPE / PURPOSE

invoice-organizer 是发票场景的专用整理技能，具备领域特定的信息提取能力。它从非结构化文件中提取结构化数据，将混乱的财务凭证转化为可检索、可汇总、可交接的标准化档案。

适用场景
准备税务申报需要整理财务凭证时；管理跨多个供应商的企业支出时；从混乱的下载文件夹或邮件附件中整理收据时；需要为会计提供结构化的发票清单时；建立自动化的 ongoing 记账归档流程时。

不适用场景

CONTRAINDICATION

无发票文件、或仅需处理少量（< 5 张）且已有明确分类时，使用该技能反而会增加不必要的复杂度。此时手动整理更为高效。

02

核心能力

Extract

信息提取

从 PDF、图片、邮件附件中读取供应商名称、发票号、日期、金额、商品描述、支付方式

Rename

统一重命名

按 YYYY-MM-DD Vendor - Invoice - ProductOrService.pdf 格式标准化文件名

Classify

智能分类

按供应商、支出类别（软件、办公、差旅等）、时间段或税务类别归档

Multi-format

多格式支持

PDF、扫描件（JPG/PNG）、邮件附件、截图、银行对账单

Preserve

原始保留

整理过程中保留原始文件，创建副本或硬链接

Report

报表生成

可选输出 CSV 汇总表，方便会计对账

03

指令流程概览

步骤 操作 技术细节
1. 扫描目录 定位目标文件夹中的所有发票相关文件 递归扫描，识别常见发票格式与命名模式
2. 逐文件提取 PDF：文本提取；图片：OCR 识别；模糊文件：使用文件名线索、文件创建日期作为 fallback 识别 "Invoice Date"、"Total"、"Invoice #" 等关键词
3. 标准化命名 按 YYYY-MM-DD Vendor - Invoice - Product.pdf 重命名 日期统一为 ISO 8601 格式，Vendor 名称规范化
4. 分类归档 移动到按供应商/类别/年份组织的目录结构 支持多级目录：Vendor/Year/ 或 Year/Category/
5. 生成报表 输出 CSV（可选），包含所有发票的明细信息 字段：日期、供应商、金额、类别、文件名、原始路径
04

与 ys-powers 的关联

「信息提取 → 标准化命名 → 分类归档 → 报表生成」的流水线可复用到任何「从非结构化文件中提取结构化数据」的场景。

SKILL ANALYSIS / PIPELINE PATTERN

与 file-organizer 的关系

RELATIONSHIP

file-organizer 是通用文件整理，invoice-organizer 是发票场景的专用版本，具备领域特定的信息提取能力。两者共享「扫描 → 识别 → 归类」的底层逻辑，但 invoice-organizer 增加了财务语义理解和税务分类规则。

借鉴价值评估

VALUE ASSESSMENT

中等价值。适合自由职业者、小企业和需要自行管理财务的开发者。注意 OCR 准确性受图片质量影响。其流水线设计模式（信息提取 → 标准化命名 → 分类归档 → 报表生成）可复用到其他领域，如合同整理、病历归档、票据管理等。

实施前需澄清的问题

  • 目标用户的主要发票来源是什么？（PDF 扫描件 / 手机拍照 / 邮件附件 / 银行对账单）
  • 归档分类的优先级：按供应商、按支出类别、按税务年度，还是混合策略？
  • 是否需要与现有会计软件（如 QuickBooks、Xero）集成，还是独立 CSV 导出即可？
  • 对 OCR 错误的容忍度如何？是否需要人工复核环节？
  • 原始文件的保留策略：硬链接、副本、还是移动归档？
