Skill

theme-factory

为幻灯片、文档、报告或 HTML 页面应用专业字体与配色主题的工具包。内置 10 套预设主题，每套包含协调的调色板和字体搭配，支持一键应用与自定义主题生成。

来源: awesome-claude-skills 维护: Composio / 社区 许可: Apache 2.0

定位与触发时机

theme-factory 是一个视觉风格配置工具，专注于为各类文档和演示材料快速应用标准化的设计系统。它在以下场景发挥价值：

适用场景

何时使用 theme-factory

  • 需要统一多份文档或幻灯片的视觉风格时
  • 创建演示文稿希望快速应用专业配色时
  • 需要为不同受众（商务、创意、学术）选择合适视觉风格时
  • 现有主题都不满足需求，需要生成自定义主题时

不适用场景

当已有明确品牌规范且需严格遵守时（如 Anthropic 品牌物料），应使用 brand-guidelines 而非 theme-factory。前者是「约束」，后者是「选择」。

其他核心能力

能力 2

主题展示

通过 theme-showcase.pdf 直观展示所有主题效果，让用户在决策前充分预览。

能力 3

一键应用

选中主题后自动将配色和字体统一到整个 artifact，无需手动调整每个元素。

能力 4

自定义主题

基于用户描述生成新的配色和字体组合，扩展预设库无法覆盖的个性化需求。

指令流程概览

1

展示主题库

向用户展示 theme-showcase.pdf，呈现全部 10 套预设主题的视觉效果

2

获取选择

询问用户偏好哪个主题，或根据受众特征推荐合适选项

3

等待确认

获得明确的主题选择，避免假设或默认应用

4

应用主题

读取对应主题文件并统一应用到 artifact，完成视觉风格配置

详细分析

与 brand-guidelines 的关系：brand-guidelines 强制执行特定品牌规范（如 Anthropic），theme-factory 提供灵活的视觉风格选择。前者是「约束」，后者是「选择」。两者互补而非替代。

与 canvas-design 的关系：canvas-design 创作原创视觉艺术，theme-factory 应用标准化设计系统。前者解决「从无到有」的创意需求，后者解决「从乱到整」的统一需求。

借鉴价值：其「展示 → 选择 → 应用」的三步流程是任何「样式配置」功能的通用模式。无论是主题选择、模板应用还是配置向导，都可以采用这一交互范式。

搬运建议：中等价值。适合需要频繁创建演示文稿或文档的团队。注意 theme 定义依赖 themes/ 目录下的具体文件，迁移时需同步处理资源依赖。

评估清单

  1. 01 团队是否经常需要为不同受众创建多份风格各异的文档或演示？
  2. 02 现有工作流中是否存在「每次从零设计配色」的重复劳动？
  3. 03 是否有明确的主题资源目录（themes/）可供管理和扩展？
  4. 04 是否需要自定义主题生成能力，还是预设主题已足够覆盖场景？
  5. 05 与 brand-guidelines 的边界是否清晰——何时强制品牌，何时灵活选择？
