document-skills

一套专业的办公文档处理技能集，覆盖 Word（docx）、PDF、PowerPoint（pptx）、Excel（xlsx）四类核心格式的创建、编辑、分析和转换。

来源：awesome-claude-skills 维护者：Composio / 社区 许可证：混合（docx/pdf 为 Proprietary）

定位与触发时机

document-skills 专注于传统办公文档的自动化处理，与 ys-powers 的 html-anything 形成互补：HTML 适合 Web 展示，Office 文档适合正式交付。

适用场景

需要创建或修改 .docx、.pdf、.pptx、.xlsx 文件；从现有文档中提取文本、表格或元数据；合并、拆分或转换文档格式；处理文档中的修订痕迹或批注。

不适用场景

仅需阅读文档内容且已有其他工具（如 pandoc）可用时。此时应优先使用现有工具，避免过度工程化。

重要提示

对于法律、学术、政府类文档，Redlining 修订模式是强制要求。这确保了所有修改都可追溯、可审计，符合专业文档处理的合规标准。

与 ys-powers 的关联

document-skills 在 ys-powers 生态中的定位、借鉴价值与搬运建议。

能力互补

html-anything 擅长生成 HTML 页面；document-skills 专注于传统办公文档。HTML 适合 Web 展示，Office 文档适合正式交付。

借鉴价值

DOCX 的「修订模式（Redlining）」工作流对任何需要「安全编辑他人文档」的场景都有参考价值。

搬运建议

中等价值。若 ys-powers 使用者经常需要处理 Office 文档，值得搬运。注意部分子 skill 使用 Proprietary 许可证。
