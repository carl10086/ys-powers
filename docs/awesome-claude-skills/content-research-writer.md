# content-research-writer

## 定位

作为写作搭档，协助完成从选题、调研、大纲、草稿到润色的全流程内容创作，同时保持作者的独特语调和风格。

## 触发时机

- 撰写博客、文章、新闻稿或教程时
- 需要为内容添加引用和参考文献时
- 想要改进开头（hook）以抓住读者注意力时
- 希望获得逐段反馈而非一次性全文评价时
- 撰写需要数据来源支撑的技术文档或案例研究时
- **不适用**：纯创意写作（诗歌、小说）或高度个人化的私密内容

## 核心能力

1. **协作式大纲**：帮助将零散想法组织为结构化的内容大纲
2. **调研辅助**：查找相关信息并添加规范引用
3. **Hook 优化**：强化文章开头，提升吸引力
4. **逐段反馈**：在写作过程中实时评审每个章节
5. **语调保持**：维持作者原有的写作风格和语气
6. **引用管理**：自动添加和格式化参考文献
7. **迭代打磨**：支持多轮修改，逐步提升内容质量

## 指令流程概览

1. **明确写作项目**：通过 5-6 个澄清问题了解主题、受众、长度、目标和风格
2. **协作式大纲**：用结构化 Markdown 构建文章骨架（Hook → 引言 → 主体 → 结论）
3. **调研与引用**：针对大纲中的关键点搜索资料并添加引用
4. **逐段撰写与反馈**：每完成一段即获得评审意见，边写边改
5. **全文润色**：最终检查流畅度、清晰度和一致性

```bash
mkdir ~/writing/my-article-title
cd ~/writing/my-article-title
touch article-draft.md
claude
```

## 与 ys-powers 的关联

- **与 ys-powers 现有能力的关系**：ys-powers 中无专门的内容创作 skill。`content-research-writer` 填补了「知识型内容生产」的空白
- **借鉴价值**：其「澄清问题 → 大纲 → 逐段反馈」的协作流程可复用到任何需要结构化输出的写作场景（如技术文档、设计文档、会议纪要）
- **搬运建议**：高价值。内容创作是通用需求，且该 skill 的交互模式（问答式引导）与 ys-powers 的 `brainstorming` skill 互补
