# invoice-organizer

## 定位

自动读取发票和收据文件，提取关键信息（日期、金额、供应商等），按统一规则重命名并分类归档，将数小时的手动记账压缩为几分钟。

## 触发时机

- 准备税务申报需要整理财务凭证时
- 管理跨多个供应商的企业支出时
- 从混乱的下载文件夹或邮件附件中整理收据时
- 需要为会计提供结构化的发票清单时
- 建立自动化的 ongoing 记账归档流程时
- **不适用**：无发票文件、或仅需处理少量（< 5 张）且已有明确分类时

## 核心能力

1. **信息提取**：从 PDF、图片、邮件附件中读取供应商名称、发票号、日期、金额、商品描述、支付方式
2. **统一重命名**：按 `YYYY-MM-DD Vendor - Invoice - ProductOrService.pdf` 格式标准化文件名
3. **智能分类**：按供应商、支出类别（软件、办公、差旅等）、时间段或税务类别归档
4. **多格式支持**：PDF、扫描件（JPG/PNG）、邮件附件、截图、银行对账单
5. **原始保留**：整理过程中保留原始文件，创建副本或硬链接
6. **报表生成**：可选输出 CSV 汇总表，方便会计对账

## 指令流程概览

1. **扫描目录**：定位目标文件夹中的所有发票相关文件
2. **逐文件提取**：
   - PDF：文本提取，识别 "Invoice Date"、"Total"、"Invoice #" 等关键词
   - 图片：OCR 识别可见文本
   - 模糊文件：使用文件名线索、文件创建日期作为 fallback
3. **标准化命名**：按 `YYYY-MM-DD Vendor - Invoice - Product.pdf` 重命名
4. **分类归档**：移动到按供应商/类别/年份组织的目录结构
5. **生成报表**：输出 CSV（可选），包含所有发票的明细信息

## 与 ys-powers 的关联

- **与 file-organizer 的关系**：`file-organizer` 是通用文件整理，`invoice-organizer` 是发票场景的专用版本，具备领域特定的信息提取能力
- **借鉴价值**：其「信息提取 → 标准化命名 → 分类归档 → 报表生成」的流水线可复用到任何「从非结构化文件中提取结构化数据」的场景
- **搬运建议**：中等价值。适合自由职业者、小企业和需要自行管理财务的开发者。注意 OCR 准确性受图片质量影响
